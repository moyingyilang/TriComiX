哪些还是空白。写在一处，是为了验证时不必翻代码注释。

## 四、怎么测

```bash
# 只打印将要访问的地址，不联网
probe.sh eh "关键词" 1 dry

# EH 完整链路（当前环境会超时，需换网络）
probe.sh eh "关键词" 1 full

# Pica：登录后跑完整链路（密码走环境变量，避免进入进程列表）
TRICOMIX_PASS='你的密码' probe.sh pica "关键词" 1 full 你的邮箱

# 收藏
TRICOMIX_PASS='你的密码' probe.sh pica "" 1 fav 你的邮箱
```

探针会逐步打印并**指出失败发生在哪一环**，失败不会被伪装成空结果。

## 五、单测覆盖

所有单测都用**我们自己写的合成样本**（HTML/JSON），真实结构来自对参照实现的静态阅读。
合成样本能证明"解析逻辑对给定形状是自洽的"，**不能证明"真实页面就是这个形状"** ——
后者只能由真实环境验证。
