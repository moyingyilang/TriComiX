# 已验证 / 未验证清单

本文件是 TriComiX 的**诚实账本**：哪些只过了合成样本的单测，哪些有真实环境的证据，哪些还没碰过。
写给将来的自己与使用者看，避免"编译通过就当能用"。

更新方式：拿到真实环境结果就补一行（含现象）。**不要**把"请求到达了服务端"写成"验证通过"。

## 一、真实环境证据（有据可查）

日期均为 2026-10-07（本会话实测）。

### Pica（哔咔）

| 环节 | 证据 | 备注 |
| --- | --- | --- |
| 登录 | 探针登录成功；**使用者在手机上登录也成功** | 曾是 401/1005，根因是三处协议差异（见下） |
| 搜索 | 返回 20 条真实结果（标题/封面/作者） | 使用者手机上搜索同样正常 |
| 详情 | 标题、作者、标签正确 | 响应为 `data.comic`（单数） |

| 页列表 | 26 页 | |
| 取图 | 第 1 页真实图片地址 | `storage-b.picacomic.com/...` |

**结论：Pica 全链路已在真实环境跑通。**

修正过的三处协议差异（都曾导致 401/1005）：

1. **`nonce` 必须是固定常量**，不是每请求随机；
2. 必须发 **`User-Agent`**（`okhttp/3.8.1`）；
3. `app-build-version` 应为 **45**（原用 44），且 **`app-uuid` 用固定值**（`defaultUuid`）、
   **`Content-Type` 所有请求都带**。

另经逐字核对：`api-key` 与 HMAC 密钥与完整客户端**完全一致**。

## 三、环境限制（会影响验证方式）

| 现象 | 影响 | 应对 |
| --- | --- | --- |
| 主机（Termux）DNS 只返回 IPv6，且无 IPv6 路由 | `git push` 必失败 | 从容器解析 IPv4，用 `GIT_SSH_COMMAND="ssh -o HostName=<ip> -p 443"` 推送 |
| 容器网络经 tun0，出口**时通时不通** | 探针可能超时 | JVM 加 `-Djava.net.preferIPv4Stack=true`；失败多为瞬时，重试即可 |
| 容器网络不可达 ≠ 协议错 | 早期多次把超时误判为协议问题 | 区分"HTTP 000 超时"与"服务端返回错误码"再下结论 |

## 四、怎么测（不需要界面）

```bash
# 自检：不联网、不需要账号
probe.sh eh "" 1 selfcheck

# 真实链路（EH 无需登录）
probe.sh eh "关键词" 1 full

# 真实链路（Pica 需登录；密码走环境变量，避免进入进程列表）
TRICOMIX_PASS='密码' probe.sh pica "关键词" 1 full 账号

# 开发期核对原始响应（用来钉死真实键名）
gradle :probe:rawDump -PrawArgs="<comicId>"
```
